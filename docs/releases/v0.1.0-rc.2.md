# Paperwork 0.1.0 RC2 — Windows and Linux preview

**Preview, not the finished release.** This is the first release with a Linux AppImage. Both packages were built, checked and published by the `Desktop packages` GitHub Actions workflow from this tag.

## Downloads

- `Paperwork_0.1.0_x64-setup.exe`: Windows x86_64 NSIS installer.
- `Paperwork_0.1.0_amd64.AppImage`: Linux x86_64. Built on Ubuntu 22.04; it needs glibc 2.35 or later. Make it executable (`chmod +x`) and run it. Other distributions have not been tested.
- `Paperwork-linux-corresponding-sources.zip`: the exact Ubuntu source packages (`.dsc`, upstream archives and Debian patches) for the Linux libraries in the AppImage's dependency set. Keep it with the AppImage if you redistribute it.
- `Paperwork-windows-x86_64-third-party-notices.zip`, `Paperwork-linux-x86_64-third-party-notices.zip`: the license notices that also ship inside each package.
- `SHA256SUMS-windows-x86_64.txt`, `SHA256SUMS-linux-x86_64.txt`: verify downloads before running them.

**Both packages are unsigned.** Windows SmartScreen may show an unrecognized-publisher warning. Use copies of non-sensitive documents and review every output. Save wanted results before closing; native cache cleanup is best-effort, not secure erasure.

Application code is MIT. Bundled libraries keep their own licenses. Optional engines and models are separately licensed and require consent before download.

## What the workflow checked

On both platforms:

- Frontend tests and production build; native security and application crate tests; Python worker and packaging regression tests.
- The frozen worker with no Python on `PATH`, and its packaged license resources.
- The packaged native host's worker self-test, then CHECKS_PLACEHOLDER packaged document-operation checks that independently read the generated PDFs, Office documents and images.

Windows: silent installation of this exact installer into a fresh directory, then the checks above against the installed files.

Linux: the AppImage extracted without FUSE and its `AppRun` run under Xvfb for the checks above. A post-bundle audit maps every shared library in the AppImage to its Ubuntu package, copied notice and verified exact source in the source ZIP. No AGPL or GPL-only library is shipped; GTK's unused TIFF image loader is left out because it depends on GPL-2+ JBIG-KIT. The application's own TIFF handling is unaffected.

## Not tested

- Interactive use on either platform: GUI, file pickers, save dialogs, desktop integration and uninstall.
- Linux distributions other than the Ubuntu 22.04 build runner.
- Optional OCR, Office, FFmpeg and AI engine/model packs. They are separate downloads with their own release status.
