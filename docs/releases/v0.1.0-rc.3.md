# Leafsmith 0.1.0 RC3 — renamed from Paperwork

**Preview, not the finished release.** This is the first release under the name Leafsmith. Up to 0.1.0 RC2 the app was called Paperwork. Both packages were built, checked and published by the `Desktop packages` GitHub Actions workflow from this tag.

## Renamed from Paperwork

- The app, its window and its files are now called Leafsmith. The GitHub repository moved to `ClawPick2026/leafsmith`; old repository links redirect. The website moved to https://leafsmith.lakebed.app, and paperwork.lakebed.app forwards there.
- The app ID changed to `io.github.clawpick2026.leafsmith`. Leafsmith does not read Paperwork's settings, job cache or installed optional components. Download optional components again in Leafsmith.
- Leafsmith installs alongside Paperwork RC2 rather than replacing it. On Windows, uninstall Paperwork separately if you no longer need it.

## Other changes since RC2

- Drag on page and image previews to set crop areas and annotation or signature boxes. Results show a preview rendered from each generated file.
- Light and dark themes in the desktop app and on the website.
- Drawn signatures are placed as a top-most stamp, above form fields and comments.
- PDF translation can embed a TrueType (`.ttf`) font you select. Summaries take an optional output language.

## Downloads

- `Leafsmith_0.1.0_x64-setup.exe`: Windows x86_64 NSIS installer.
- `Leafsmith_0.1.0_amd64.AppImage`: Linux x86_64. Built on Ubuntu 22.04; it needs glibc 2.35 or later. Make it executable (`chmod +x`) and run it.
- `Leafsmith-linux-corresponding-sources.zip`: the exact Ubuntu source packages (`.dsc`, upstream archives and Debian patches) for the Linux libraries in the AppImage's dependency set. Keep it with the AppImage if you redistribute it.
- `Leafsmith-windows-x86_64-third-party-notices.zip`, `Leafsmith-linux-x86_64-third-party-notices.zip`: the license notices that also ship inside each package.
- `SHA256SUMS-windows-x86_64.txt`, `SHA256SUMS-linux-x86_64.txt`: verify downloads before running them.

On Arch Linux, the `AUR package` workflow builds this release's AppImage into the AUR package `leafsmith-bin`. It publishes the package only if the build, install, namcap and headless self-test checks pass on Arch Linux.

**Both packages are unsigned.** Windows SmartScreen may show an unrecognized-publisher warning. Use copies of non-sensitive documents and review every output. Save wanted results before closing; native cache cleanup is best-effort, not secure erasure.

Application code is MIT. Bundled libraries keep their own licenses. Optional engines and models are separately licensed and require consent before download.

## What the workflow checked

On both platforms:

- Frontend tests and production build; native security and application crate tests; Python worker and packaging regression tests.
- The frozen worker with no Python on `PATH`, and its packaged license resources.
- The packaged native host's worker self-test, then 22 packaged document-operation checks that independently read the generated PDFs, Office documents and images.

Windows: silent installation of this exact installer into a fresh directory, then the checks above against the installed files.

Linux: the AppImage extracted without FUSE and its `AppRun` run under Xvfb for the checks above. A post-bundle audit maps every shared library in the AppImage to its Ubuntu package, copied notice and verified exact source in the source ZIP. Its license tripwire, which rejects AGPL and GPL-only runtime libraries, passed; reviewed exceptions and their reasons are listed in `docs/BUILDING.md`.

## Not tested

- Interactive use on either platform: GUI, file pickers, save dialogs, desktop integration and uninstall.
- Upgrading from or installing alongside Paperwork RC2.
- Linux distributions other than the Ubuntu 22.04 build runner. The AUR workflow's Arch Linux checks are headless only.
- Optional OCR, Office, FFmpeg and AI engine/model packs. They are separate downloads with their own release status.

Report problems in this repository's Issues. Do not attach private documents, passwords or API keys.
